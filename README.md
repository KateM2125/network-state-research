## Research Areas

- **Network State Taxonomy** — NSCF 6-axis classification, NSDI composite index, 32-entity illustrative cohort
- **Credit Risk** — NSCRF 5-pillar first-principles creditworthiness methodology, NS-AAA through NS-D notch scale
- **Economic Measurement** — NSEI 10-metric composite, Gross Community Product (GCP), Diplomatic Recognition Readiness Index (DRRI)
- **Sustainability** — NS-ESG 13-indicator four-pillar framework (E/S/G + Digital Sovereignty); novel TVL+gas protocol emissions allocation
- **Special Economic Zones** — SEZ history, governance unbundling, SEZ → Network State progression
- **Australian Federation** — A 19th-century infrastructure-event Network State as precedent
